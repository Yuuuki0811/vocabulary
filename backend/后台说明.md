# 内部后台版

启动：在此目录运行 `python3 server.py`，打开 http://127.0.0.1:8770/ 。仅本机使用，不是手机公网地址。当前没有发布或修改 GitHub。

已实现：同源会话、访问限制、服务器端 AI 请求、连接真实请求验证、生成结果回填、失败保留词卡。密钥仅从服务器环境变量 BUSINESS_OPENAI_KEY 读取，模型从 BUSINESS_OPENAI_MODEL 读取；不写入 HTML 或浏览器存储。API 使用独立计费，与 ChatGPT 账号订阅不同。

尚未实现/开通：ChatGPT 官方网页登录授权、跨设备云词库同步、ChatGPT 对话保存到词库。没有可用凭证时后台返回未开通，不能自动生成。现有用户记录仍存在各自浏览器的 localStorage；新网址不会自动继承原网址记录，可用备份恢复。

官方开源直接授权流程要求用户设备上的 127.0.0.1 回调监听器和受保护的本地凭证存储，不能将这一入口直接替换成手机公网网页回调。托管网页登录客户端需要官方接入资格与注册配置。公开托管前需完整实现用户账户、HTTPS、安全会话、限额及授权验证；此内部服务器不可直接公开。

验证：5 项后台测试通过（未登录、错误 Host、跨域、未配置、模拟生成回填），网页脚本语法通过，首页 HTTP 200。模拟测试不代表真实 AI 或 ChatGPT 授权已验证。
