# 商语 · 商务英语记忆

手机网页：https://yuuuki0811.github.io/vocabulary/

包含500个商务词条、蓝色主题、球球橡果奖励、100项成就、录入与三层切分、复习测试、造句批改记录、录音本机保存。网页词库和学习记录保存在各自浏览器，支持JSON备份（录音需单独下载）。

## 后台现状

GitHub Pages只托管网页。自动生成、AI批改、AI路线、两人账户与排行榜需要运行后台；目前仅本机后台已验证，未部署公网后台，不会自动连接作者电脑。网页明确显示服务未连接。

本机运行：进入backend目录，用Python3运行server.py，访问http://127.0.0.1:8770/。通过http://127.0.0.1:8770/setup配置阿里云百炼API Key、北京业务空间ID和qwen-plus模型。密钥只保存到本机私密配置文件；请勿提交到GitHub。

backend/server.py是本机测试服务，不应直接公开。账户数据库和API配置均排除在仓库之外。公网部署还需HTTPS、认证与访问限制、数据库和调用限额。

球球已替换为提供的GLB松鼠模型，使用Idle待机和EatAcorn喂食动画。网页模型保留Idle、EatAcorn和Happy三段动画，原始模型不覆盖。模型加载较大，首次访问会先显示预览图。新图标尚待提供。
